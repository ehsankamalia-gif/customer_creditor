Import Stock

Load or sync motorcycle stock from a supplier portal export (e.g. a dealer stock list). Accepts an Excel (.xlsx) or CSV file straight from the portal's own Export button, or pasted table text. Expected columns: Purchase Order, Recv. Date, Model, Colour, Engine No, Chassis No, Status — column names are matched flexibly, and a title row above the real header (e.g. a report heading) is detected and skipped automatically. Re-running the import is safe: existing units (matched by chassis number) only have their purchase reference, date and status refreshed — pricing, location and notes you've entered are never overwritten, and a unit already marked Sold here is never changed back.
